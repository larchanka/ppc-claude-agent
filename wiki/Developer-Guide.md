# Developer Guide

This guide covers contributing to `ppc-code-ai-agent`, working with the modular build system, running tests, CI workflows, and maintaining codebase context graphs.

---

## 1. Development Workflow

### Modifying Code
Always edit the modular files in `src/*.pl`. **Never edit `code-agent.pl` directly**, as it is an assembled artifact generated by `build.pl`.

```bash
# 1. Edit the relevant module in src/ (e.g. src/ui.pl)
# 2. Assemble and verify code-agent.pl
perl build.pl

# 3. Check synchronization
perl build.pl --check
```

---

## 2. Running Tests

The test suite is located in `t/` and uses standard Perl `Test::More`.

```bash
# Run all tests via prove
prove -I. t/*.t

# Run a specific test suite in verbose mode
prove -v -I. t/banner.t
prove -v -I. t/auto_manual_commands.t
prove -v -I. t/build.t
```

### Self-Healing Test Suite
All test scripts in `t/` automatically detect if `code-agent.pl` is missing on disk and invoke `build.pl` on demand. This allows fresh checkouts to run tests immediately without pre-compilation.

### Mock Curl Transport (`t/mock_curl.pl`)
Tests execute with `$ENV{CLAUDE_CURL}` pointed to a lightweight mock curl script. No live API calls or network connections are made during standard test execution.

---

## 3. Continuous Integration (GitHub Actions)

A GitHub Actions workflow is configured in `.github/workflows/test.yml`:
* **Triggers**: On pushes and pull requests to `main`.
* **Runner**: `ubuntu-latest`.
* **Steps**:
  1. Checks out repository (`actions/checkout@v4`).
  2. Runs `perl build.pl` to compile `code-agent.pl`.
  3. Runs `perl build.pl --check` to ensure source-to-artifact synchronization.
  4. Runs `prove -I. t/*.t` to execute all 400+ unit and integration tests.

## 4. Codebase Context & Symbol Graphs

The repository maintains an automated AST symbol and call graph inside `.context_cache/` and `context/` for AI agents:

```bash
# 1. Scan AST across codebase
python3 /Users/mikhaillarchanka/.gemini/config/skills/codebase-context-generator/scripts/ast_scanner.py --root . --summary

# 2. Build dependency graph
python3 /Users/mikhaillarchanka/.gemini/config/skills/codebase-context-generator/scripts/dependency_graph.py --manifest .context_cache/ast_manifest.json

# 3. Update symbol graph & export signature index
python3 /Users/mikhaillarchanka/.gemini/config/skills/codebase-context-generator/scripts/symbol_graph.py \
  --manifest .context_cache/ast_manifest.json \
  --save-graph .context_cache/symbol_graph.json \
  --export-signatures context/signatures.md

# 4. Verify context integrity and markdown links
python3 /Users/mikhaillarchanka/.gemini/config/skills/codebase-context-generator/scripts/verify_context.py --root .
```

### Fast Signature & Call-Graph Navigation
During development, you can query function signatures and call hierarchies instantly:
```bash
# Find function signature, parameter types, and location
python3 /Users/mikhaillarchanka/.gemini/config/skills/codebase-context-generator/scripts/symbol_graph.py --find "show_banner"

# Trace callers of a function
python3 /Users/mikhaillarchanka/.gemini/config/skills/codebase-context-generator/scripts/symbol_graph.py --callers "confirm_tool"

# Trace what a function calls
python3 /Users/mikhaillarchanka/.gemini/config/skills/codebase-context-generator/scripts/symbol_graph.py --callees "call_api"
```
